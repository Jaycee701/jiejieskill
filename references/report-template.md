## 九、Phase 7：报告输出 (Reporting)

### 9.1 报告结构

```
1. 执行摘要 (Executive Summary)
   - 1-2页，面向管理层
   - 整体安全态势评估
   - 关键发现与业务风险
   - 优先级修复路线图

2. 方法论与范围 (Methodology & Scope)
   - 测试方法论说明（PTES/OWASP/NIST）
   - 测试范围清单
   - 测试类型（黑盒/灰盒/白盒）
   - 工具列表
   - 测试时间窗口

3. 技术发现详情 (Technical Findings)
   - 每个漏洞单独章节：
     · 漏洞标题
     · CVSS v3.1/v4.0 评分 + 向量
     · 严重程度（Critical/High/Medium/Low/Info）
     · 影响系统/URL
     · 漏洞描述 + CWE 编号
     · 复现步骤（截图+请求/响应）
     · 影响分析
     · 修复建议（具体、可操作）
     · 参考链接

4. 攻击路径叙事 (Attack Narrative)
   - Kill Chain 图示
   - 从初始访问到最终目标的完整路径
   - MITRE ATT&CK 技术映射

5. 修复优先级矩阵 (Remediation Roadmap)
   - 立即修复（<7天）
   - 短期修复（7-30天）
   - 中期修复（30-90天）
   - 长期建议（>90天）

6. 附录 (Appendix)
   - 完整工具列表
   - 术语表
   - 原始扫描数据
   - 未利用但存在风险项
```

### 9.2 风险评级标准

| 严重程度 | 条件（满足其一） |
|---------|---------------|
| **Critical** | 直接获取系统/域控权限、核心数据泄露、无需认证的RCE |
| **High** | SQL注入、未授权访问敏感数据、已验证的提权 |
| **Medium** | XSS、CSRF、配置缺陷、信息泄露 |
| **Low** | 低影响信息泄露、SSL/TLS弱配置 |
| **Info** | 建议性改进、最佳实践偏离 |

### 9.3 CVSS 评分速查
```
AV:N (网络) / AV:A (相邻) / AV:L (本地) / AV:P (物理)
AC:L (低复杂度) / AC:H (高复杂度)
PR:N (无需权限) / PR:L (低权限) / PR:H (高权限)
UI:N (无需交互) / UI:R (需要交互)
S:U (范围不变) / S:C (范围改变)
C/I/A: N/L/H (机密性/完整性/可用性：无/低/高)
```
